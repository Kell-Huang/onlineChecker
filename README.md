onlineStatusChecker
====================

onlineStatusChecker — SFCC x Productsup Feed Diff Checker

A Windows-first desktop tool that compares the SFCC Global Online Status (GOS)
export against per-country Productsup comparison feeds, samples the SKUs that
are missing from the feed, queries the Productsup channel stage API and writes
a five-sheet Excel report.

Requirements
------------

- Python 3.10+
- Windows, macOS or Linux (Windows recommended)
